# **Real-Time Google Play Store Data Analytics using Python**

## **Project Overview**
This project focuses on analyzing Google Play Store data to extract meaningful insights using Python. It includes three major tasks: generating a word cloud for 5-star reviews, comparing free vs paid apps in top categories using a dual-axis chart, and visualizing app size vs rating for the Games category using a bubble chart. The project incorporates data filtering, time-based visualization, and advanced data analytics techniques.

## **Features**
- **Word Cloud Analysis**: Extracts keywords from 5-star reviews in the Health & Fitness category.
- **Dual-Axis Comparison**: Compares installs and revenue for free vs paid apps in the top three categories.
- **Bubble Chart Visualization**: Analyzes the relationship between app size and rating in the Games category.
- **Time-Based Conditional Display**: Ensures visualizations are shown within specific time windows.
- **Data Cleaning & Filtering**: Preprocessing techniques applied for handling missing values, duplicates, and stopwords.

## **Technologies Used**
- **Python** (Pandas, NumPy, Matplotlib, Seaborn, NLTK, Datetime)
